# Allow Copy Paste

Restore fundamental browser interactions on websites that attempt to block them via JavaScript.

## 🚀 Overview

**Allow Copy Paste** is a browser freedom tool that restores your ability to right-click, select text, and use context menus on sites that try to restrict these basic functions. Regain control over your browser experience.

## ✨ Key Features

- **Restore Interactions**: Re-enables Right-Click, Copy, Paste, and Text Selection.
- **Context Menu Recovery**: Bypasses JavaScript-based context menu blocks.
- **Persistent Rules**: Save sites where you want the extension to remain active.
- **Lightweight Injector**: Minimal performance overhead with document-start injection.
- **One-Click Toggle**: Enable or disable the restoration features instantly via the popup.

## 🛠️ Installation

1. Download or clone this repository.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the root folder of this project.

## 📖 Usage

1. Navigate to a site that restricts browser interactions.
2. Click the extension icon in your toolbar.
3. Toggle the switches to enable Copy/Paste or Right-Click functionality.
4. The page will be "fixed" instantly or upon reload.
